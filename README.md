# Mobilya Katalog

Mobilyaları sergilemek için hazırlanmış, sunucu gerektirmeyen basit bir katalog sitesi.

- `index.html` dosyasına çift tıklayınca tarayıcıda açılır.
- Açık / koyu mod, kategori filtresi, ürün detay penceresi, WhatsApp butonu, belgeler ve KVKK metni içerir.
- Tüm içerik (firma bilgileri, ürünler, belgeler, KVKK) `urunler.js` dosyasından düzenlenir.
- Ayrıntılar için `NASIL-DUZENLENIR.txt` dosyasına bakın.

Firma adı, iletişim bilgileri, belge numaraları ve KVKK metni örnektir.
Örnek ürün fotoğrafları [Unsplash](https://unsplash.com) üzerinden gösterilir.
